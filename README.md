# P.I.M.P.

**Psycho-Intelligence Musical Protocol**

> Music = Identity + Tension + Release

Intent-first AI music production system. One psychological intent per song. Functional genre fusion. Measurable anti-trope discipline.

---

## What it is

P.I.M.P. is a disciplined studio loop, not a prompt-to-sludge generator.

Every track begins with a locked **Spec Block**, then routes through a hard sequence:

**Genre DNA \to Structure \to Anti-Trope QC \to Sound \to Release**

- **Primary Spine** owns structure + rhythm  
- **Secondary Color** owns texture / harmony / vocals  
- **K2 Anti-Trope** runs three-pass QC (Detect \to Validate \to Veto) with Context Dependency scoring and a rewrite ladder  
- Style prompts stay \u22641000 characters and paste-ready for generation tools  
- Lyrics use section tags + staging notes  

The system is built for streaming-era impact: early hook, concrete physical grounding, evolving emotion, and anti-echo discipline so it does not degrade into its own clich\u00e9s.

## Core principles

1. One psychological intent per song  
2. Genre fusion must be functional (Spine owns structure; Color owns texture)  
3. Emotional impact > technical complexity  
4. Anti-trope discipline is non-negotiable  
5. Concrete physical grounding over abstract filler  

---

## Knowledge modules

| Module | Responsibility |
|--------|----------------|
| **K5** | Genre DNA + Spine/Color fusion rules |
| **K1** | Structure templates + modification commands |
| **K2** | Anti-trope three-pass QC, CDS scoring, rewrite ladder |
| **K3** | Style/production prompt construction + lyrics formatting |
| **K4** | Release package \u2014 cover art, video hooks, launch assets |

Routing order is locked: **K5 \to K1 \to K2 \to K3 \to K4**
