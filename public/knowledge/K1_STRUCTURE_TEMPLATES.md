# K1 — Song Structure Templates

*Consolidated from P.I.M.P. Section 20 (canonical v1.0) and Evidence-Based Song Structure Templates — 2026-07.*

## §1 Section taxonomy

- **Intro** — establishes key, tempo, mood, groove. **Cold Open** — no buffer; starts on vocal/hook. **Hook Intro** — opens with chorus material for instant capture.
- **Verse / Verse A/B** — narrative delivery; changing lyrics over consistent melody. A/B = deliberate variation, same function.
- **Pre-Chorus / Lift** — recurring ramp that builds momentum into the chorus. It must LIFT (energy, harmony, or tension) — it is not an extra verse.
- **Chorus / Refrain** — repeating emotional payoff; primary hook container. Refrain = shorter repeated phrase embedded in the verse.
- **Post-Chorus / Tag** — distinct unit after the chorus that extends the hook (new vocable/riff) without adding narrative.
- **Bridge / Middle 8** — one-time contrast and turning point, usually after chorus 2.
- **Breakdown** — strips layers for tension. **Drop** — explosive arrival after a build. **Half-time** — rhythmic reinterpretation without tempo change (use as a directive).
- **Solo / Instrumental** — featured non-vocal spotlight; often the climactic lead-in to the final chorus.
- **Build / Rise → Climax → Aftermath** — cinematic macro-sections mirroring a story arc.
- **Outro / Reprise / Button** — closure by fade, motif return, or hard stop.

Genre synonyms: "middle eight" = bridge (UK pop/rock); "hook" = chorus (hip-hop); "drop" = chorus equivalent (EDM).

## §2 World Context Rule

If the user doesn't specify distribution context, choose one and let it bias the structure:
- **Radio-era**: legible verse/chorus/bridge cycles; bridge late; 3–4 min.
- **Streaming-era** (default): short intro, early hook, post-chorus common, tighter runtime.
- **Short-form (TikTok/Shorts)**: plan a Short-Form Hook Cut (≤40s contiguous excerpt containing hook + peak identity) even when the full song is longer.

Hook timing (sourced): a Top-10-focused industry analysis (Hit Songs Deconstructed) reports first payoff averaging ~0:42, with chorus-before-verse openings occurring. Default to early payoff when commercial impact is desired; delay only when the emotional plan explicitly requires it.

## §3 The 10 templates

Each entry: structure → psychological function → hook policy → variations → when to choose.

### 1. Radio Rock / Alt Rock
Intro (riff) → V1 → (Pre) → Chorus → V2 → (Pre) → Chorus → Bridge OR Solo → Final Chorus → Outro (tag/button)
Identity in verse storytelling; tension in pre/bridge contrast; release in anthemic chorus. Arcs: Chase→Capture, Confrontation→Resolution. **Hook:** standard-to-early. **Variations:** replace bridge with solo; add post-chorus riff; shorten to ABABCB; cold-open with chorus fragment. **Choose when:** guitar-driven spine, chorus must feel "earned but inevitable." (Anchor: "Since U Been Gone.")

### 2. Heartland Rock / Country Rock
Intro (short, sets scene) → V1 (story) → Chorus (thesis/title) → V2 (story advances) → Chorus → Bridge (new angle) → Final Chorus (bigger, optional double) → Outro (tag/fade)
Concrete narrative detail in verses; chorus states the truth; bridge reframes (regret→resolve). Arcs: Ritual→Ascension, Dominance→Surrender. **Hook:** standard-to-early; title is the hook. **Variations:** no bridge (third-verse twist); add pre-chorus for modern country lift; double chorus ending. **Choose when:** lyric-first storytelling over steady 4/4. (Anchor: "Country Roads.")

### 3. Modern Pop (Streaming-Era)
Hook Intro OR Cold Open → V1 → Pre → Chorus → Post-Chorus → V2 → Pre → Chorus → (Post) → Bridge OR Breakdown → Final Chorus (double) → Tag/Outro
Rapid identity (short verse); explicit momentum in pre; arrival/plateau in chorus; post-chorus extends payoff without re-litigating narrative. Arcs: Absurdity→Joy, Chaos→Control. **Hook:** early (within ~15–30s). **Variations:** chorus-before-verse; no bridge (pure repetition); double post-chorus; 40s short-form cut. **Choose when:** maximal hook density, streaming intent. Default fallback template. (Anchor: "Shape of You.")

### 4. Singer-Songwriter / Acoustic Ballad
Intro (minimal motif) → V1 → V2 (variation) → Chorus/Refrain → V3 → Bridge (emotional pivot) → Final Chorus OR Refrain → Outro (reprise/resolve)
Slow burn; sparse sections keep focus on lyric truth; single pivot unlocks release. Mode: Ballad. **Hook:** standard/refrain-style; longer setup justified when payoff is the point. **Variations:** AABA (32-bar); strophic verse-with-refrain; minimal/no bridge; double outro. **Choose when:** sparse instrumentation, introspection-first arc. (Anchor: "Yesterday.")

### 5. Indie / Alternative (Looser Forms)
Intro (texture) → V1 → Chorus OR Refrain → V2 → Instrumental/Break → Chorus → C-Section ("new world," optional) → Final Chorus OR no-return ending → Outro
Coherence with permission to deviate: unexpected C-sections, chorus avoidance, shape-shifts. Arcs: Chaos→Control, Absurdity→Joy. **Hook:** variable — early if commercial, delayed if the concept needs bloom. **Variations:** omit bridge; extended instrumental midsection; ABABC no-final-chorus ending; freeform tempo/mood shift. **Choose when:** texture/attitude over repetition; Mode = Absurd. (Anchor: "1979.")

### 6. Metal / Hard Rock (Riff-Module Logic)
Intro (main riff module) → V1 (riff + vocal) → (Pre) → Chorus/motif → V2 → (Pre) → Chorus → Breakdown OR Bridge → Solo (optional) → Final Chorus → Outro (riff return; button)
Riffs are identity modules; breakdown shifts weight so the final chorus lands as conquest or collapse. Metal sustains an energy cycle even when verse/chorus labels blur — do NOT write it as pop-with-distortion. Arcs: Confrontation→Resolution, Ritual→Ascension. **Hook:** standard; the motif may be riff-based, not lyric-based. **Variations:** multiple solos; half-time breakdown; chorusless forms; extended intro. **Choose when:** riff anchors + aggressive percussion; dark/aggressive tone flags. (Anchor: "Enter Sandman.")

### 7. Hip-Hop / Trap (Verse-Hook Core)
Intro/Cold Open (ad-lib, optional) → Hook → Verse 1 (16 bars) → Hook → Verse 2 → Hook → Bridge/Outro (or Verse 3)
Hook = slogan/emotional headline; verses deliver detail and escalation. Ordering is flexible — hook-first openings are more common than in rock/pop. Arcs: Dominance→Surrender, Absurdity→Joy. **Hook:** early, often first. **Variations:** pre-hook (1–2 bars); feature verse replaces V2; "switch" (beat change) late; double hook ending; verse-heavy. **Choose when:** bar-structured flow and hook loop carry identity.

### 8. EDM / Dance (Build-Drop Cycles)
Intro (8–16 bars, mixable) → Break/Verse (theme) → Build 1 → Drop → Breakdown (valley) → Build 2 → Drop (bigger/varied) → Outro (mixable)
Tension-and-release by design; the drop is the functional chorus. Arcs: Chaos→Control, Ritual→Ascension. **Hook:** drop = hook; for streaming-first hybrids, use hook-preview intros. **Variations:** start-with-drop; vocal topline over drop; multiple breakdown cycles; short-form Intro→Build→Drop→Tag. **Choose when:** four-on-the-floor + risers; energy contour IS the song. Build without tension is a failure (§7).

### 9. R&B / Soul (Vocal Space + Vamp)
Intro (mood) → V1 → (Pre) → Chorus → V2 → (Pre) → Chorus → Bridge (harmonic/emotional pivot) → Final Chorus → Vamp/Outro (ad-libs; dissolve or button)
Vocal nuance first; the vamp is a controlled release zone (ad-libs, call-and-response, extended groove). **Hook:** standard-to-early. **Variations:** extended vamp; no pre-chorus; ad-lib stack on final chorus; breakdown instead of bridge. **Choose when:** vocal timbre, runs, and groove lead; late-stage catharsis needed.

### 10. Cinematic Trailer / Hybrid Orchestral Rock (Three-Act)
Act I: Setup/Prologue (state the destination early) → Act II: Build (layers, momentum) → Act III: Climax (full impact) → Aftermath (resolve, button, or sting)
Mirrors narrative escalation; climax motif replaces the chorus. Mode: Cinematic; Vetting: Trailer/Sync. **Hook:** early motif statement even if full climax comes later (editor usability). **Variations:** three-act with stop-downs; second climax; hybrid drop before final hit; fourth-act sting. **Choose when:** orchestral + hybrid percussion + rock edge; trailer-ready flags.

## §4 Selection rule (locked)

When the user omits structure, select by this priority:
1. **Performance Vetting** (trailer/club/radio/short-form target, if stated)
2. **Genre DNA** (K5 — which sections the genre relies on: riffs, drops, hooks, vamps)
3. **Optional Mode** (Ritual/Anthem/Ballad/Absurd/Cinematic)
4. **Narrative Arc / Emotion Path**
5. Fallback: **Modern Pop (Streaming)** baseline — then immediately modify it to match Genre DNA, Arc, and Emotion Path.

## §5 Modification & compression commands

**Modification:** Add Pre-Chorus (lift) · Add Post-Chorus (hook extension) · Extend Bridge (16 bars or key change) · Add Breakdown / Solo / Drop · Remove Intro (→ Cold Open) · Cold Open Hook · Double Chorus Ending (vary it — avoid monotony) · Add Vamp Outro / Reprise / Button Ending.
**Compression:** Condense Structure · Remove Verse 2 · Remove Bridge · Short-Form Version · Extended Climax · Instrumental Break Extension · Loop Chorus Ending · Radio Edit · Streaming Hook Emphasis · **Short-Form Hook Cut** (≤40s contiguous excerpt containing the hook + peak identity; prefer hook-first).

## §6 Decision tree

Trailer/sync → Cinematic. Club/DJ → EDM. Beat-centric rap with hook cycles → Hip-Hop/Trap. Riff-centric heavy → Metal. Mainstream streaming pop, max hook density → Modern Pop. Story-led radio country/heartland → Heartland. Band rock with classic payoff → Radio Rock. Intimacy/lyric clarity first → Ballad. Novelty within coherence → Indie. Vocal-performance-forward with ad-lib release → R&B/Soul. Unclear DNA → Modern Pop baseline, modified per flags/arc/emotion.

## §7 Failure modes (template quality gate)

Reject or repair a structure that shows any of: wandering sections that don't escalate · chorus later than ~30–45s under streaming intent · no contrast (bridge/breakdown) before the final chorus · pre-chorus that doesn't lift · post-chorus that is just "more chorus" with no function · EDM drop without a real build · metal written as pop-with-distortion · hip-hop without a clear hook identity · R&B ending abruptly with no catharsis · trailer cue hiding its destination past Act I · arc mismatch (e.g., no resolution in the outro of a Confrontation→Resolution song) · final chorus identical to the first (cross-check K2 gate QG-4 — vary a line, add a line, or show the bridge's consequence).
